# PostPilot

PostPilot 是一个本地桌面端创作者发布助手。用户输入一份原始内容后, 工具会生成微信公众号, 知乎, B 站, 小红书四个平台的适配版本, 并保留本地历史记录。

## 当前功能

- 输入标题和正文, 生成四个平台版本
- 固定使用 `deepseek-v4-flash` 模型
- 未配置 DeepSeek API Key 时, 自动使用本地规则生成可演示版本
- 使用本地 SQLite 保存历史记录, 内容审查结果和发布记录
- 生成后可逐个平台编辑标题, 摘要, 正文和标签, 并保存回历史记录
- 支持 Markdown, HTML 和纯文本的平台预览, 预览内容会在渲染前净化
- 支持发布前 AI 内容审查, 法律风险标红, 价值观风险标黄
- 法律风险未处理时会拦截真实发布和模拟发布
- 支持复制, 导出, 模拟发布和统一发布任务记录
- 支持在应用设置中保存平台账号配置, 删除配置和执行授权校验
- 支持微信公众号官方 API 创建草稿, 可选择提交发布任务
- 支持发布就绪状态面板, 设置账号总览和发布记录详情
- 通过平台适配器预留官方 API 发布和浏览器辅助发布扩展点

## 第三方依赖和框架

- Electron, 桌面端外壳和主进程能力
- React, 渲染层界面
- Vite 和 electron-vite, 本地开发和构建
- TypeScript, 类型约束
- Node 24 `node:sqlite`, 本地 SQLite 数据库
- Zod, DeepSeek 返回结构校验
- dotenv, 本地环境变量读取
- lucide-react, 按钮和状态图标
- marked, Markdown 内容渲染
- DOMPurify, HTML 预览净化
- Vitest, 单元测试

## 原创功能部分

- 平台适配器结构和四个平台的本地适配规则
- DeepSeek 调用封装和本地规则回退逻辑
- DeepSeek 内容审查封装, 本地风险词兜底, 红黄风险分级和发布拦截逻辑
- SQLite 历史记录, 内容审查结果和发布记录建库
- 平台草稿编辑和保存流程
- Markdown, HTML 和纯文本预览渲染接入流程
- 平台账号配置, 授权校验, 加密保存和删除流程
- 微信公众号官方发布连接器, 包含 access_token, 草稿创建, 发布提交, 重试和回执记录
- 发布就绪状态, 账号总览和发布记录详情的界面展示逻辑
- 统一 Publisher 发布任务层, 可扩展模拟发布, 导出, 官方 API 和浏览器辅助发布
- Electron IPC 安全桥接
- 黑白简约三栏创作者工作台界面

当前没有复用外部项目或过去项目的业务代码片段。如后续复用历史代码, 必须在 PR 描述中注明来源和修改范围。

## 真实发布说明

- 微信公众号: 支持官方 API。需要在设置中填写 AppID, AppSecret 和封面素材 Media ID。公众号后台还需要配置接口 IP 白名单。默认创建草稿, 可在发布目标中选择提交发布任务。
- 知乎: 当前未发现稳定公开的官方写入发布接口, 工具会返回失败回执, 不会伪装真实发布成功。
- B 站: 官方投稿链路需要视频稿件文件和授权。当前文本草稿只能导出或保留发布任务回执, 不会伪装真实发布成功。
- 小红书: 当前未发现稳定公开的普通笔记官方写入发布接口, 工具会返回失败回执, 不会伪装真实发布成功。

## 环境变量

应用内不提供模型切换, 也不提供 `.env` 修改入口。开发时可以在本机已有环境中提供 `DEEPSEEK_API_KEY` 和 `DEEPSEEK_BASE_URL`。不填写时仍可使用本地规则生成平台版本和本地风险词审查。
